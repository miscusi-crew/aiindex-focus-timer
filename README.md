# Focus Timer

A simple Pomodoro timer: focus, short break, repeat.

Work in focused blocks with breaks in between. After four focus sessions you get a longer break.

- Change the lengths to suit you; they're remembered
- A soft chime plays when a block ends
- The time left shows in the tab title

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
